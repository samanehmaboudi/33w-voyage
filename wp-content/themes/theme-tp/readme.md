# TP1 – Étape 3 : Club de voyage

## Auteur
Samaneh Maboudi  
Projet réalisé dans le cadre du cours **33W - Introduction à un système de gestion de contenu**

## Description
Ce projet est un site WordPress personnalisé pour un **club de voyage**.  
Il présente différentes destinations classées par catégories (Aventure, Culturel, Zen, etc.).

Le thème a été développé sur mesure avec PHP, HTML, SCSS, et respecte les exigences du TP1 – Étape 3 :
- Menu principal avec logo
- Section hero avec description du club
- Galerie d'images (catégorie `galerie`)
- Section « Destinations populaires »
- Pied de page complet (liens, réseaux sociaux, coordonnées)
- Pages de catégories (`category.php`)
- Pages individuelles (`single.php`)
- Page de résultats de recherche (`search.php`)
- Intégration des images à la une
