# 33W - Introduction à un système de gestion de contenu ## TP1 - Étape #3: Club de voyage ### Auteur Samaneh Mahboudi ### Description Ce projet consiste à créer un site WordPress pour un club de voyage permettant aux membres de découvrir et réserver des destinations variées. Chaque destination est classée par catégorie afin de faciliter la recherche selon les préférences des utilisateurs. Le site est conçu avec un thème personnalisé et est déployé sur Web Hosting Canada (WHC).
